En este proyecto de data wrangling se realiza la preparacion de datos que precentan incosistencias en la calidad y completitud, para posteriormente elaborar un analisis sobre los registros musicales de dos ciudades diferentes en distintos días

-Se examinan y preparan los nombres de las columnas para llegar a una estandarizacion

-Se abordan valores duplicados y ausenes

- Se analiza la actividad de los usuarios y se detectan variaciones segun el dia de la semana y ciudad
